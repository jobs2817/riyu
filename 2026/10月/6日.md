# 10月6日｜日期 1日～10日的读法

1日～10日用的是和语固有读法（特殊读法），要单独记；11日以后基本是「数字＋にち」。

| 日期 | 读法 | 罗马音 | 备注 |
| --- | --- | --- | --- |
| 1日 | ついたち | tsuitachi | 特殊读法；「いちにち」意思是“一天” |
| 2日 | ふつか | futsuka | |
| 3日 | みっか | mikka | |
| 4日 | よっか | yokka | 注意别和 8日 ようか 混淆 |
| 5日 | いつか | itsuka | |
| 6日 | むいか | muika | |
| 7日 | なのか | nanoka | 也读 なぬか |
| 8日 | ようか | yōka | 长音 よう |
| 9日 | ここのか | kokonoka | |
| 10日 | とおか | tōka | 写成 とおか，不是 とうか |

---

## 容易混的几组

- **4日 よっか vs 8日 ようか**：よっか 是促音（小っ），ようか 是长音。
- **1日 ついたち vs 一日 いちにち**：日期“1号”说 ついたち；“一整天”说 いちにち。
- **10日 とおか**：和「十（とお）」同音，长音写 お。

## 顺带记住的特殊日期

- 14日：じゅうよっか
- 20日：はつか
- 24日：にじゅうよっか

## 例句

今日は10月6日（むいか）です。
今天是 10 月 6 号。

来月の1日（ついたち）に日本へ行きます。
下个月 1 号去日本。

テストは8日（ようか）です。
考试在 8 号。
