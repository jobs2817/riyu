# JLPT N5 语法整理

下面是一份按**学习顺序和用途**整理的 JLPT N5 语法速查表。先说明范围：JLPT 官方**不公布固定的 N5 语法清单**，所以不存在能保证“考试只考这些”的官方全集；以下覆盖常见 N5 教材和备考资料的核心内容，并把各教材分级不一致的内容放在最后。[JLPT 官方说明](https://www.jlpt.jp/e/faq/index.html)、[N5 能力要求](https://www.jlpt.jp/sp/e/about/levelsummary.html)

**记号**：N＝名词，V＝动词，Aい＝い形容词，Aな＝な形容词；「普通形」指不用「です／ます」的形式。

## 一、基本句型与判断

| 语法 | 意思与用法 | 例句 |
|---|---|---|
| NはNです | ……是……；「は」提示话题，读 *wa* | 私は学生です。＝我是学生。 |
| NはNではありません／じゃありません | ……不是…… | 今日は休みではありません。＝今天不休息。 |
| NはNでした／ではありませんでした | 名词句的过去肯定／否定 | 昨日は休みでした。＝昨天休息。 |
| ～ですか | 疑问；一般不需要改变语序 | 田中さんは先生ですか。＝田中是老师吗？ |
| Nも | 也 | 私も学生です。＝我也是学生。 |
| NのN | 所属、属性、产地等 | これは私の本です。＝这是我的书。 |
| N1はN2が～ | 整体话题中的某一部分 | 私は日本語が好きです。＝我喜欢日语。 |
| ～ね／～よ | 「ね」求认同、确认；「よ」告知对方信息 | いい天気ですね。＝天气真好啊。／おいしいですよ。＝很好吃哦。 |

日语的基本语序是**话题／主语—宾语—谓语**，助词放在名词后面；谓语通常在句尾。[日本国际交流基金「まるごと」基础语法](https://www.marugoto-online.jp/a1/support/all/intro_grammar/)

## 二、指示词、疑问词

| 类别 | 形式 | 用法与例句 |
|---|---|---|
| 指东西 | これ／それ／あれ／どれ | これは何ですか。＝这是什么？ |
| 修饰名词 | この／その／あの／どの＋N | この本は面白いです。＝这本书很有趣。 |
| 指地点 | ここ／そこ／あそこ／どこ | トイレはどこですか。＝洗手间在哪里？ |
| 礼貌地指方向、地点、人 | こちら／そちら／あちら／どちら | 受付はこちらです。＝接待处在这边。 |
| 问人 | だれ／どなた | あの人はだれですか。＝那个人是谁？ |
| 问事物 | 何（なに／なん） | 何を食べますか。＝吃什么？ |
| 问时间 | いつ／何時／何曜日 | いつ行きますか。＝什么时候去？ |
| 问方式、状态 | どう／どんな＋N | どうですか。＝怎么样？／どんな映画ですか。＝是什么样的电影？ |
| 问数量、价格 | いくつ／いくら／何人等 | これはいくらですか。＝这个多少钱？ |
| 问原因 | どうして／なぜ | どうして休みましたか。＝为什么请假了？ |

**こ・そ・あ**通常分别指靠近说话人、靠近听话人、远离双方的事物。「ど」用于提问。疑问词的更多分类可参考[「まるごと」疑问词表](https://www.marugoto-online.jp/a1/support/all/appendix_04/)。

## 三、助词：N5 最重要的部分

| 助词 | 核心作用 | 例句 |
|---|---|---|
| は | 提示话题、形成对比 | 私はコーヒーを飲みます。＝我喝咖啡。 |
| が | 标出主语或新信息；常与「好き・上手・あります」等搭配 | 猫がいます。＝有一只猫。 |
| を | 动作的对象，读 *o* | 本を読みます。＝读书。 |
| に | 到达点、存在地点、具体时间、动作对象 | 学校に行きます。＝去学校。／七時に起きます。＝七点起床。 |
| へ | 移动方向，读 *e* | 日本へ行きます。＝去日本。 |
| で | 动作地点；手段、工具、交通方式 | 図書館で勉強します。＝在图书馆学习。／バスで行きます。＝坐公交去。 |
| と | 和；与某人一起；引用的基础用法 | 友達と行きます。＝和朋友去。 |
| や | 不完全列举，“……之类” | りんごやバナナを買いました。＝买了苹果、香蕉等。 |
| か | 疑问；名词之间表示“或” | お茶か水をください。＝请给我茶或水。 |
| の | 所属、修饰；有时可代替前面提过的名词 | 私のかばんです。＝我的包。 |
| も | 也 | 兄も行きます。＝哥哥也去。 | 
| から | 起点；原因 | 九時から働きます。＝从九点开始工作。／寒いですから、帰ります。＝因为冷，我要回去了。 |
| まで | 终点、截止 | 五時まで働きます。＝工作到五点。 |
| より | 比较基准 | 電車はバスより速いです。＝电车比公交快。 |
| だけ | 仅、只 | 水だけ飲みます。＝只喝水。 |
| ね／よ | 句末确认、告知 | そうですね。／大丈夫ですよ。 |

**最容易混淆的三组：**

- **に／で**：存在于某地用「に」——部屋に猫がいます；在某地做动作用「で」——部屋で勉強します。
- **は／が**：「は」提出谈论对象；「が」指出是谁或是什么。例：だれが来ましたか。田中さんが来ました。
- **に／へ**：两者都可表示移动方向；「に」更强调到达点，「へ」更强调朝向。

助词搭配和例句可对照[日本国际交流基金的 A1 助词表](https://www.marugoto-online.jp/a1/support/all/appendix_02/)。

## 四、动词变形

N5 至少要认出**ます形、辞书形、ない形、て形、た形**。动词分为一类（五段）、二类（一段）和三类（する、来る）。

### 1. 礼貌体

| 形式 | 意思 | 例：食べる |
|---|---|---|
| ～ます | 现在／将来肯定 | 食べます＝吃／会吃 |
| ～ません | 现在／将来否定 | 食べません＝不吃 |
| ～ました | 过去肯定 | 食べました＝吃了 |
| ～ませんでした | 过去否定 | 食べませんでした＝没吃 |

日语的“非过去”形式也可以表示将来：**明日行きます**＝明天去。[「まるごと」动词变形表](https://www.marugoto-online.jp/a1/support/all/appendix_05/)

### 2. 普通形

| 动词 | 辞书形 | ない形 | た形 | て形 |
|---|---|---|---|---|
| 一类：書く | 書く | 書かない | 書いた | 書いて |
| 一类：読む | 読む | 読まない | 読んだ | 読んで |
| 二类：食べる | 食べる | 食べない | 食べた | 食べて |
| 三类：する | する | しない | した | して |
| 三类：来る | 来る | 来ない（こない） | 来た（きた） | 来て（きて） |

一类动词的**て形／た形**按词尾记：

| 辞书形词尾 | て形 | た形 | 例 |
|---|---|---|---|
| う・つ・る | って | った | 買う→買って→買った |
| む・ぶ・ぬ | んで | んだ | 読む→読んで→読んだ |
| く | いて | いた | 書く→書いて→書いた |
| ぐ | いで | いだ | 泳ぐ→泳いで→泳いだ |
| す | して | した | 話す→話して→話した |

**例外：行く→行って→行った。**  
「ない形」的一类动词通常把词尾改成 *a* 段再加「ない」；「う」改为「わ」，如**買う→買わない**。

## 五、形容词与名词的变化

| 词类 | 非过去肯定 | 非过去否定 | 过去肯定 | 过去否定 |
|---|---|---|---|---|
| い形容词 | 高いです | 高くないです | 高かったです | 高くなかったです |
| な形容词 | 静かです | 静かではありません | 静かでした | 静かではありませんでした |
| 名词 | 学生です | 学生ではありません | 学生でした | 学生ではありませんでした |

常用口语也会说「静かじゃないです」「学生じゃなかったです」。

| 语法 | 用法 | 例句 |
|---|---|---|
| Aい＋N | い形容词直接修饰名词 | 高い山＝高山 |
| Aな＋な＋N | な形容词修饰名词要加「な」 | 静かな町＝安静的城镇 |
| Aい→く＋V | 把い形容词变成副词 | 早く起きます。＝早起。 |
| Aな→に＋V | 把な形容词变成副词 | 静かに話します。＝轻声说话。 
| Aい→くなる／Aな→になる | 变得…… | 寒くなりました。＝变冷了。／元気になりました。＝精神好起来了。 |
| ～くて／～で | 连接两个性质 | 安くておいしいです。＝便宜又好吃。／静かで便利です。＝安静又方便。 |

**特殊词「いい」**变化时用「よ」：**よくない、よかった、よくなかった**。

## 六、存在、位置和数量

| 语法 | 用法 | 例句 |
|---|---|---|
| Nがあります | 有无生命的东西、植物等 | 机があります。＝有桌子。 |
| Nがいます | 有人或动物 | 子どもがいます。＝有小孩。 |
| 场所にNがあります／います | 某处有…… | 部屋に猫がいます。＝房间里有猫。 |
| Nは场所にあります／います | ……在某处 | 本は机の上にあります。＝书在桌上。 |
| Nの上／下／中／前／後ろ／隣 | 方位 | 駅は銀行の隣です。＝车站在银行旁边。 |
| 数量词＋あります／います | 数量 | りんごが三つあります。＝有三个苹果。 |
| 时间量＋V | 动作持续多久 | 二時間勉強しました。＝学了两个小时。 |
| 时间点に＋V | 何时做 | 八時に出ます。＝八点出发。 |

数量词需要配合量词，例如**一人、二人、三人**；**一つ、二つ、三つ**；**一冊、二冊**。常见读法有不规则变化，可参考[「まるごと」量词表](https://www.marugoto-online.jp/a1/support/all/appendix_01/)。

## 七、请求、邀请、愿望、能力

| 语法 | 接续与意思 | 例句 |
|---|---|---|
| Nをください | 请给我…… | 水をください。＝请给我水。 |
| Vてください | 请做…… | ここに名前を書いてください。＝请在这里写名字。 |
| Vないでください | 请不要做…… | 写真を撮らないでください。＝请不要拍照。 |
| Vましょう | 一起……吧 | 行きましょう。＝走吧。 |
| Vませんか | 邀请：要不要……？ | 一緒に食べませんか。＝要不要一起吃？ |
| Vます形去ます＋たいです | 想做…… | 日本へ行きたいです。＝想去日本。 |
| Nがほしいです | 想要某物 | 新しいかばんがほしいです。＝想要新包。 |
| V辞书形＋ことができます | 能够做…… | 日本語を話すことができます。＝会说日语。 |
| Nができます | 会做某事、会某项技能 | 料理ができます。＝会做饭。 |
| Nが好き／嫌い／上手／下手です | 喜好或擅长程度 | 音楽が好きです。＝喜欢音乐。 |

「～たい」表示**说话人自己的愿望**最自然；询问别人可用「何を食べたいですか」。

## 八、て形的主要句型

| 语法 | 意思 | 例句 |
|---|---|---|
| Vて、V | 按顺序做两件事 | 朝ご飯を食べて、学校に行きます。＝吃完早饭去学校。 |
| Vてから、V | 做完前项之后再做后项 | 手を洗ってから、食べます。＝洗手后再吃。 |
| Vています | 正在进行；也可表示持续状态 | 今、本を読んでいます。＝现在正在读书。／東京に住んでいます。＝住在东京。 |
| Vてもいいです | 可以做…… | ここに座ってもいいです。＝可以坐这里。 |
| Vてはいけません | 不可以做…… | ここで写真を撮ってはいけません。＝这里不可以拍照。 |

注意：**住んでいます**通常是“住在……”，并非“此刻正在搬进去”。

## 九、时间、顺序、比较与连接

| 语法 | 意思 | 例句 |
|---|---|---|
| V辞书形＋前に | 做……之前 | 寝る前に歯を磨きます。＝睡前刷牙。 |
| Nの前に | ……之前 | 食事の前に手を洗います。＝饭前洗手。 |
| Vた形＋後で | 做……之后 | 食べた後で散歩します。＝吃完后散步。 |
| Nの後で | ……之后 | 授業の後で会います。＝下课后见。 |
| ～時 | ……的时候 | 子どもの時、日本にいました。＝小时候在日本。 |
| AはBより～ | A比B更…… | 今日は昨日より暑いです。＝今天比昨天热。 |
| AとBと、どちらが～ | A和B哪个更…… | 犬と猫と、どちらが好きですか。＝狗和猫更喜欢哪个？ |
| Aのほうが～ | A更…… | 猫のほうが好きです。＝更喜欢猫。 |
| ～から、～ | 因为……所以…… | 雨ですから、行きません。＝因为下雨，所以不去。 |
| ～が、～ | 但是；也可作委婉铺垫 | 安いですが、おいしいです。＝虽然便宜，但很好吃。 |
| そして／それから | 然后；补充、按顺序叙述 | ご飯を食べました。それから、出かけました。＝吃完饭后出门了。 |
| でも | 但是；常放在新句句首 | 行きたいです。でも、時間がありません。＝想去，但没时间。 |

## 十、常见副词和固定搭配

这些经常与语法题一起出现，最好连同后面的肯定或否定形式一起记。

| 搭配 | 意思 | 例句 |
|---|---|---|
| いつも／よく＋肯定 | 总是／经常 | よく本を読みます。＝经常看书。 |
| ときどき＋肯定 | 有时 | ときどき映画を見ます。＝有时看电影。 |
| あまり＋否定 | 不太…… | あまり食べません。＝不太吃。 |
| ぜんぜん＋否定 | 完全不…… | ぜんぜん分かりません。＝完全不懂。 |
| もう＋过去／完成 | 已经…… | もう食べました。＝已经吃了。 |
| まだ＋否定 | 还没有…… | まだ食べていません。＝还没吃。 |
| たくさん／少し | 很多／一点 | 少し分かります。＝懂一点。 |
| いちばん | 最…… | これがいちばん安いです。＝这个最便宜。 |

「よく／あまり」等频率搭配也见于[「まるごと」A1 例句](https://www.marugoto-online.jp/a1/support/lesson/5_3/)。

## 十一、教材分级不一致：学完核心后补充

有些教材把以下内容放在 N5 后段，有些放在 N4 前段。为了做到“涉及的都整理”，建议认识并会读：

| 语法 | 意思 | 例句 |
|---|---|---|
| Vたり、Vたりします | 列举几个有代表性的动作 | 日曜日は本を読んだり、映画を見たりします。＝周日会读书、看电影等。 |
| Vたことがあります | 有过某种经历 | 日本へ行ったことがあります。＝去过日本。 |
| ～ので | 因为…… | 雨が降ったので、出かけませんでした。＝因为下雨，没有出门。 |
| Vたほうがいいです | 最好做…… | 早く寝たほうがいいです。＝最好早点睡。 |
| Vないほうがいいです | 最好不要做…… | 無理しないほうがいいです。＝最好别勉强。 |

**复习顺序**：先掌握助词和三类词的变形，再练「て形」句型，最后集中辨析「は／が」「に／で」「あります／います」。这几组会影响后面大量语法的理解。
