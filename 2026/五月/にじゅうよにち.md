# 日语日期 1～30 读法

|------|------|------|
| 1日 | ついたち | 一日 |

| 7日 | なのか | 七日 |
| 8日 | ようか | 八日 |
| 9日 | ここのか | 九日 |
| 10日 | とおか | 十日 |

## 20～30 日

| 日期 | 读法 | 汉字 |
|------|------|------|
| 20日 | はつか | 二十日 |
| 21日 | にじゅういちにち | 二十一日 |
| 22日 | にじゅうににち | 二十二日 |
| 23日 | にじゅうさんにち | 二十三日 |
| 24日 | にじゅうよっか | 二十四日 |
| 25日 | にじゅうごにち | 二十五日 |
| 26日 | にじゅうろくにち | 二十六日 |
| 27日 | にじゅうしちにち / にじゅうななにち | 二十七日 |
| 28日 | にじゅうはちにち | 二十八日 |
| 29日 | にじゅうくにち | 二十九日 |
| 30日 | さんじゅうにち | 三十日 |

## 要点

- 1～10 日：全部特殊读法，需单独记忆
- 14 日、24 日：用 **よっか**（不是 よんにち）
- 20 日：单独记 **はつか**（不是 にじゅうにち）
- 21～29 日：にじゅう + 1～9 的读法
